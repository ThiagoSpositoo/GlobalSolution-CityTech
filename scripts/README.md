# Scripts — caminho obrigatório DevOps

Reservado para Azure CLI e **`script-bd.sql`** com DDL da solução .NET escolhida para nuvem. Os arquivos ainda não foram implementados.

Scripts futuros deverão declarar pré-requisitos, parâmetros, recursos, região e estimativa de custo; usar variáveis de ambiente, tratar erro e permitir reexecução controlada. Não incluir credenciais reais. Provisionamento depende de autorização explícita.

DDL aqui deverá corresponder às migrações do domínio .NET; PL/SQL da disciplina Banco permanece em `database/oracle/`. Se o alvo cloud mudar para Java, revisar essa correspondência antes de gerar artefatos.
