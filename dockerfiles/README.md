# Dockerfiles — caminho reservado

O PDF DevOps exige Dockerfiles nesta pasta quando a solução avaliada usar containerização. Não há aplicações implementadas para construir imagens nesta etapa.

Compose local usa imagens de infraestrutura de fornecedores; isso não equivale a ter Dockerfiles de aplicação. Confirmar com professor o alcance da condição se o deploy .NET usar App Service por pacote. Se containerizar Java/.NET na entrega, criar Dockerfiles reais com contexto da raiz e builds reproduzíveis.
