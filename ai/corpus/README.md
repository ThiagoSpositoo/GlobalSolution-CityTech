# Corpus de referência

Reservado para documentos curtos sobre categorias e critérios de prioridade de **demonstração**. Cada documento deve ter ID, título, fonte/autoria, licença quando aplicável, versão/data e escopo.

Não apresentar critérios inventados como norma de prefeitura. Não incluir dados pessoais de cidadãos. Registrar preparação/chunking e modelo de embeddings escolhido; manter os casos de avaliação separados.
