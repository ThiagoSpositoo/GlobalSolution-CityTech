# Plano inicial de avaliação

Reservado para entradas rotuladas por humanos e resultados reais de execução. Não existe dataset nem métrica medida nesta etapa.

Cobertura proposta: todas as categorias, casos ambíguos, entrada incompleta, fora do escopo, indisponibilidade do modelo e instruções adversariais. Guardar versão de corpus/prompt/modelo, contexto recuperado, resposta, decisão humana, latência e erro.

Critérios propostos: categoria correta, prioridade coerente, resumo fiel, JSON válido, recuperação relevante e taxa de falhas. Comparar com/sem RAG se houver tempo para justificar o aprofundamento. Proteger tokens e dados nas evidências.
