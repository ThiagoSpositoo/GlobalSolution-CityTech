# Capturas reais para o PDF de Compliance

Adicione aqui somente capturas reais e revisadas do Azure DevOps, em PNG, JPG, JPEG ou WebP.

Use nomes ordenáveis, por exemplo:

- `01_backlog_hierarquia.png`
- `02_feature_07_aceite.png`
- `03_test_case_58_steps.png`
- `04_test_plan_execucao.png`

Não inclua PAT, cookies, e-mails desnecessários, senhas ou abas alheias. Depois execute:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File qa/scripts/New-ComplianceDelivery.ps1
```

O gerador incorpora automaticamente as imagens e recria o PDF, o TXT e o ZIP.
